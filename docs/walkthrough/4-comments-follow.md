# Comments, Follow Mode, and Chat

Work seamlessly alongside your team with presence and communication tools:

* **Follow Mode**: Click on any participant in the CoLive Participants tree or press `Ctrl+Alt+L F` to follow their active file and cursor. Manual scrolling or clicking auto-stops following.
* **Inline Comments**: Highlight code and use the editor context menu to **Add Comment**. Threads are anchored directly to the code with CRDT relative positions so edits don't misalign discussions.
* **CoLive Chat**: Chat in real-time in the sidebar with slash commands like `/follow <name>` and `/goto <file>:<line>`.
* **Shared Diagnostics**: TypeScript and compiler errors detected on the host machine are relayed to all guests automatically.
