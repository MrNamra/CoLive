# Join a Collaboration Session

Join a session hosted by another developer without cloning repositories or configuring local development dependencies.

1. Click **Join Session** in the CoLive Activity Bar, or press `Ctrl+Alt+L J`.
2. Paste the invite link (`vscode://...`) or paste code (`sessionId.secret`).
3. CoLive securely connects to the relay and requests admission from the host.
4. Once the host approves your request, the host's workspace appears as a virtual folder under the `colive:` scheme.
5. All file reads, navigation, and CRDT synchronizations occur in real-time.
