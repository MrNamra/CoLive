# CoLive Extension

Real-time collaboration for VS Code-compatible editors.

## Features
- **Live Co-Editing**: Real-time collaborative text editing backed by Yjs CRDTs.
- **Remote Cursors**: Live visual presence, cursors, and selections.
- **Inline Comments**: Threaded code discussions anchored to lines.
- **Follow Mode**: Seamlessly follow another developer's editor viewport.
- **Session Chat**: Built-in chat channel.
